# Glanzhaus Web

Site institucional Angular do Glanzhaus.

## Preview online

Após o deploy no GitHub Pages:

**https://gabrielRsaga.github.io/glanzhaus-web/**

## Desenvolvimento local

```bash
npm install
npm start
```

Abre em http://localhost:4200/

## Atualizar o site publicado

Cada push na branch `main` republica automaticamente:

```bash
git add .
git commit -m "sua mensagem"
git push
```

O deploy leva cerca de 1–2 minutos (aba **Actions** no GitHub).
